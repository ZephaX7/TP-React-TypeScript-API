# Rick & Morty Explorer

Projet réalisé en React et TypeScript utilisant l'API Rick and Morty.

## Fonctionnalités

- Affichage des personnages
- Recherche d'un personnage
- Affichage des détails d'un personnage
- Ajout de personnages aux favoris
- Formulaire pour proposer un personnage
- Page À propos

## API

Les personnages sont récupérés depuis l'API Rick and Morty :
https://rickandmortyapi.com/

## Lancer le projet

Installer les dépendances :

npm install

Lancer le projet :

npm run dev
